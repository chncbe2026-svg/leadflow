How to deploy Code.gs (60 seconds)
  1. Open script.google.com → New project
  2. Delete the sample code, paste everything from Code.gs
  3. Click Deploy → New deployment → type Web app
  4. Execute as: Me · Who has access: Anyone
  5. Click Deploy, allow permissions, copy the /exec URL
  6. Paste it above and click Test & detect sub-sheets

Already deployed? Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy. The URL stays the same.
